# Earth Analogs

Team **3TE**'s project for the [NASA Space Apps Challenge 2026](https://www.spaceappschallenge.org/2026/), challenge *Identify Earth Locations that Analog the Permanent Moon Base Locations and Mars*.

Work in progress during the hackathon (14–15 November 2026).

## Repository layout

| Path | Contents |
|---|---|
| `pipeline/` | Python code that downloads and processes Earth, Moon and Mars data |
| `notebooks/` | Exploration and analysis notebooks |
| `app/` | Web application |
| `data/` | Local data, not committed |
| `docs/` | Challenge brief, data sources, project status |
